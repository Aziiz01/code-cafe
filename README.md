# ☕ Code-Cafe

> A lightweight platform for Tunisian cafés to easily generate and display **QR codes** for their menus and Wi-Fi credentials — built with **React** and **Node.js**.

---

## 🇹🇳 Project Overview

**Code-Cafe** is a freelance web solution tailored for coffee shops and restaurants in Tunisia. It allows business owners to create custom QR codes that link to digital menus or Wi-Fi credentials, reducing the need for printed materials and enhancing the customer experience.

Simple, fast, and mobile-friendly — made to modernize traditional hospitality services.

---

## 🛠️ Tech Stack

| Technology     | Purpose                          |
|----------------|----------------------------------|
| **React.js**   | Frontend user interface          |
| **Node.js**    | Backend API and QR generation    |
| **Express.js** | REST API server                  |
| **QRCode.js**  | QR code generation library       |
| **MongoDB** *(optional)* | Persistent storage     |
| **Tailwind CSS** | Styling & layout               |
| **Vercel / Render** | Hosting & deployment        |

---

## ✨ Features

- 📱 Generate QR codes for:
  - Digital menus (PDF, web links, etc.)
  - Wi-Fi login credentials (SSID + password)
- 🖨️ Printable QR sheets for tables or windows
- ⚙️ Custom styling options (colors, logos, etc.)
- 🌐 Mobile-first responsive design
- 🇫🇷/🇹🇳 Localized for French & Arabic (optional)
